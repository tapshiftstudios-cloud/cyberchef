# CyberChef 1.0.3 (build 6)

## Play Console — What's new

### Türkçe
- Google ile giriş seçeneği eklendi
- Şifre alanında göster/gizle (göz ikonu)
- Geliştirilmiş onboarding turu ve ilerleme göstergesi
- Ayarlar'dan geri bildirim gönderme
- Açılış ekranı alt renk uyumu düzeltildi

### English
- Sign in with Google
- Password show/hide toggle on login
- Improved onboarding tour with step progress
- Send feedback from Settings
- Splash screen bottom color fix

## Build

```powershell
flutter build appbundle --release --dart-define-from-file=.env
```

Output: `build/app/outputs/bundle/release/app-release.aab`
